How to cite us
==============

*   If you publish results generated using *ksrates*, please cite:

    Sensalari C., Maere S. and Lohaus R. *ksrates*: positioning whole-genome duplications relative to speciation events in *K*:sub:`S` distributions. *Bioinformatics*, Volume 38, Issue 2, January 2022, Pages 530–532, `https://doi.org/10.1093/bioinformatics/btab602 <https://doi.org/10.1093/bioinformatics/btab602>`__

    BibTeX format:

    .. code-block:: bibtex

        @article{sensalari2022ksrates,
            author  = {Sensalari, Cecilia and Maere, Steven and Lohaus, Rolf},
            title   = {ksrates: positioning whole-genome duplications relative to speciation events in KS distributions},
            journal = {Bioinformatics},
            volume  = {38},
            number  = {2},
            pages   = {530-532},
            year    = {2022},
            month   = {01},
            issn    = {1367-4803},
            doi     = {10.1093/bioinformatics/btab602},
            url     = {https://doi.org/10.1093/bioinformatics/btab602}
        }


*   If you use the reciprocally retained gene family analysis, introduced in version 2, please also cite:

    Tasdighian, S., Sensalari, C. & Maere, S. Using reciprocally retained gene families to detect whole-genome multiplications in plants. *Genome Biol* **27**, 152 (2026). `https://doi.org/10.1186/s13059-026-04032-y <https://doi.org/10.1186/s13059-026-04032-y>`__

    BibTeX format:

    .. code-block:: bibtex

        @article{tasdighian2026recret,
            author  = {Tasdighian, Setareh and Sensalari, Cecilia and Maere, Steven},
            title   = {Using reciprocally retained gene families to detect whole-genome multiplications in plants},
            journal = {Genome Biology},
            volume  = {27},
            number  = {1},
            pages   = {152},
            year    = {2026},
            doi     = {10.1186/s13059-026-04032-y},
            url     = {https://doi.org/10.1186/s13059-026-04032-y}
        }
